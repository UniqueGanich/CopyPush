# CopyPush 1.0.0

Маленькая утилита для Windows 10/11: при копировании по **Ctrl+C** у курсора мыши
всплывает аккуратная плашка **«Скопировано»** — она плавно поднимается вверх и растворяется.

## Что в архиве

| Файл | Размер | Что нужно |
|---|---|---|
| `CopyPush-1.0.0-win-x64.zip` | ~35 МБ | ничего, работает сразу |
| `CopyPush-1.0.0-win-x64-small.zip` | ~10 МБ | [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) |

## Установка

1. Скачайте `CopyPush-1.0.0-win-x64.zip` и распакуйте в любую папку (например `C:\Tools\CopyPush`).
2. Запустите `CopyPush.exe`.
3. Появится иконка в трее. Всё, готово — теперь **Ctrl+C** в любом приложении
   покажет плашку «Скопировано» у курсора.

Чтобы включить автозапуск, откройте меню иконки в трее → **Запускать вместе с Windows**.

### Удаление

Запустите `Uninstall.cmd` из той же папки — он уберёт автозапуск, настройки и саму программу.

## Возможности

- **Глобальная привязка Ctrl+C** — работает в любом приложении, а не только в вашем.
- **Ничего не ломает.** Ctrl+C не перехватывается: используется хук *на чтение*.
  В консоли Ctrl+C по-прежнему прерывает процесс, в играх — работает как игровая клавиша.
- **Без ложных срабатываний.** Плашка появляется, только если содержимое буфера
  действительно изменилось после нажатия.
- **Цвет системной темы.** Фон — как у системных окон, текст контрастный.
  Акцентный цвет берётся из темы Windows и подхватывается на лету.
- **Светлая и тёмная тема**, три варианта оформления, три длительности анимации.
- **Не мешает.** Окно не перехватывает клики, не активируется и не появляется в Alt+Tab.
- **Пишет журнал** в `%LOCALAPPDATA%\CopyPush\CopyPush.log` — удобно, если что-то пойдёт не так.

## Настройки (меню иконки в трее)

| Пункт | Что делает |
|---|---|
| Показывать уведомление | Вкл/выкл всю утилиту |
| Показывать при любом изменении буфера | Реагировать и на копирование правой кнопкой мыши |
| Позиция | У курсора / по центру экрана / в правом нижнем углу |
| Оформление | Системный / акцентный / контрастный |
| Длительность | Быстро / обычно / медленно |
| Запускать вместе с Windows | Вкл/выкл автозапуск |

## Требования

- Windows 10 версии 19041 (20H1) или новее
- Windows 11 — полная поддержка, включая живую смену темы
- Для «small»-варианта: [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)
- Права администратора **не нужны**

## Как это работает

1. Низкоуровневый хук клавиатуры `WH_KEYBOARD_LL` наблюдает за нажатием `Ctrl+C`
   и **не подавляет** его — вызов всегда уходит дальше в приложение.
2. Одновременно окно слушает `WM_CLIPBOARDUPDATE`. Если в течение 1.5 секунды
   после `Ctrl+C` содержимое буфера изменилось — значит копирование состоялось,
   и показывается плашка.
3. Плашка рисуется отдельным слоем окна (`AllowsTransparency`), поднимается
   анимацией `RenderTransform` и растворяется через `Opacity`.

Отсюда и отсутствие ложных срабатываний: `Ctrl+C` в терминале — это прерывание
процесса, буфер не меняется, плашка не появляется.

## Сборка из исходников

```bash
git clone https://github.com/UniqueGanich/CopyPush.git
cd CopyPush
dotnet publish -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:EnableCompressionInSingleFile=true -o out
```

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

Полный цикл (сборка + установка + запуск) — `tools\deploy.ps1`.
